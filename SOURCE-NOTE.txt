hMailServer Migration Assistant v1.0-clean - Source Package

IMPORTANT REPRODUCIBILITY NOTE

The compiled reference binary supplied in this conversation is:

  hMailServer-Migration-Assistant-v1.0-clean.exe
  SHA-256: c385434345cf1364d7c0830aba4d9194eb24f524780e06b023dcecf060f196b5

The transient build workspace that originally produced that exact binary was not retained by the execution environment. The executable itself was retained, but the exact original Go source file was not.

The source in this package is therefore a clean source reconstruction of the v1.0-clean application, based on:
- the retained v1.0-clean executable and its embedded Go function/string metadata;
- the retained migration workflow and UI behaviour from this project;
- the earlier source implementation from which the native application evolved.

It implements the same migration model and major features and builds successfully as a Windows x64 GUI executable, but it is NOT claimed to reproduce the reference EXE byte-for-byte.

No server IP addresses, mail-domain names, database passwords, Administrator password hashes, mailbox contents, or other confidential migration-session data are hard-coded in this source package.
